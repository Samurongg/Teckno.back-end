# TecnoMarket-Analytics-front-back
Para inicializar el enterno virtual colocamos el siguiente comando:
.\.venv\Scripts\Activate.ps1

Luego de ello se descargan los "Requirements.txt" atraves de un pip

El programa se ejecuta con: 
uvicorn app.main:app --reload --port 8000
Con ellos los procedimientos y las Apis desarrolladas se ejecutaran y estaran listos para consumirse de manera eficiente.
